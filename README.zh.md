# dsh-toggle-leftside

[English](README.md) | 中文

> 为**折叠态**的左侧边栏增加「悬停临时展开（peek）」能力的 DSH 客户端插件。

DSH 官方外壳把侧边栏当作二元的 `收起 ⟷ 展开` 开关，没有中间预览态。本插件从指针焦点驱动同一个 `ctx.layout.toggleSidebar()` 动作，补上一个临时的中间状态，并且在展开期间把侧边栏以**浮动抽屉**形式覆盖在主区域之上，因此主区域全程不被挤压。

## 安装

### DSH 插件
deepseek harness--> 插件 -->搜 `github:bqbs/dsh-toggle-leftside` --> 安装；
###  指令
- web
```
dsh plugin --profile web add github:bqbs/dsh-toggle-leftside
```
- desktop
```
dsh plugin --profile desktop add github:bqbs/dsh-toggle-leftside
```

验证：把侧边栏收起，把鼠标移到窗口最左缘或任意折叠图标上停留约 150ms，侧边栏应临时展开为浮动抽屉；移开约 200ms 自动收起，点击折叠按钮则固定为完全展开。

## 功能

- **悬停预览（PEEK）**：折叠态下靠近左缘即临时展开，主区域保持满宽。
- **点击固定（PINNED）**：在预览态点击折叠按钮，把它变成和原生一致的「固定展开」；再点一次才收起。
- **折叠态品牌标识**：在 Windows 标题栏的折叠按钮上补上产品品牌标识（非 Windows 轨道外壳本就显示，保持不变）。
- **设置开关**：「设置 → 左侧折叠栏」下有一个开关，存于 `localStorage`，切换即时生效，无需刷新。

## 交互与效果

状态机：

```
COLLAPSED ──鼠标悬停左缘 150ms──▶ PEEK
PEEK      ──指针离开 200ms──────▶ COLLAPSED
PEEK      ──点击折叠按钮─────────▶ PINNED
PINNED    ──点击折叠按钮─────────▶ COLLAPSED   （外壳原生行为）
```

- **浮动抽屉**：进入 PEEK 时，侧边栏内层 `*_root` 被抬出网格流（`position: fixed`）覆盖在主区域上，主区域保持折叠时的几何位置与宽度。
- **动画**：抽屉以 180ms 滑入（`left: -12px → 0`）+ 淡入（`opacity 0 → 1`）开合，只动抽屉本身，主区域不动。每次 peek 只播一次入场动画。
- **触发热区**：窗口左缘一条热区 + 折叠按钮本身。热区宽度与折叠列宽一致：Web 上即图标栏（约 56px），可悬停任意图标展开；desktop 上折叠列无宽度，回退为固定的 28px 边缘热区。
- **层级**：抽屉 `z-index: 25`，高于主区域覆盖层（20），但低于所有外壳菜单层（图标菜单 70、下拉/悬浮卡 100/101、portal 菜单/提示/Toast 1100），所以外壳菜单始终画在抽屉之上。

## 已知限制

- **仅指针驱动**：没有键盘快捷键触发 peek；触屏上因悬停语义不同，预览主要靠贴边拖动，体验不如桌面悬停。
- **依赖外壳 DOM 结构**：通过类名后缀匹配定位侧边栏/容器。对外壳类名做哈希重命名鲁棒，但若整体结构（如网格项拆分方式）变更可能失效。
- **desktop 热区较窄**：桌面端折叠列无宽度，热区回退为 28px 左缘，必须贴很左才能触发。
- **品牌标识首屏缺失**：折叠按钮上的品牌标识要等**第一次** peek 缓存到 SVG 后才出现，首次加载尚未悬停时仍显示原图标。
- **偏好按浏览器隔离**：开关存于 `localStorage`，不跨设备/浏览器同步。
- **只处理首个侧边栏列**：假定布局中只有一个左侧栏，未考虑多栏或动态增减。
- **未处理 reduced-motion**：不响应系统「减少动态效果」偏好，仍播放动效。
- **编辑后需重载**：`client.js` 通过 `window.__ModuleLoader__` 从 graph 快照加载，修改后必须重新加载窗口。
- **已展开态无作为**：侧边栏本来就展开时，插件不添加任何行为（PEEK 只能从折叠态发起）。
